## Git и состав

В корне проекта нет .git; git rev-parse --show-toplevel сообщил, что папка не является репозиторием. Поэтому уже отслеживаемых файлов и Git-истории проекта сейчас нет; проверка истории неприменима. Никакая история не переписывалась и файлы не удалялись из индекса.

Для проверки правил использован временный технический Git-каталог внутри игнорируемого .qa-stage4, без git add, коммитов или удалённых репозиториев. Основной каталог проекта не инициализировался как Git-репозиторий. Список кандидатов получен штатным Git ls-files --others --exclude-standard; правила проверены через check-ignore --no-index.

.gitignore исключает локальные .env и варианты окружения, приватные ключи/сертификатные контейнеры, .venv и проверочные окружения, .dependencies, instance, SQLite с journal/WAL/SHM, backup-каталоги и типовые копии/дампы, журналы, кэши, transfer_artifacts, архивы передачи и временные проверки. Исключения для безопасных .env.example и *.env.example сохранены. Игнорирование не обезвреживает ранее сохранённые Git-объекты, но таких объектов проекта на момент проверки нет.

Сохраняются исходники Flask, HTML/CSS/JS, WSGI-точка, фиксированные зависимости, тесты, документация и deployment-примеры. Документация содержит публичный домен и описания реального размещения, но не значения секретов. Два иллюстративных снимка в docs созданы ранее на искусственном тестовом аккаунте BrowserQA; настоящие пользовательские данные и панели аккаунтов в них не включались.
